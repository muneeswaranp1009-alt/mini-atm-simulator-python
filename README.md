# Mini ATM Simulator

A simple Python based ATM Simulator created to practice fundamentals of programming and understand how the basic operation of a bank can be performed using Python.

## Features

- Password based authentication
- Deposit money
- Withdraw money

- View account balance

- Insufficient balance validation
- Menu driven interface
- Continuous operation of an ATM
  
## Technologies Used
- Python
- 
## ATM Operations
The application provides you with the following options.

1. Add Amount
2. Withdraw
3. View Balance
4. Exit
   
## How It Works
1. The user will be prompted to enter the password for the account.
2. Once the correct password is entered, the ATM screen will appear.
3. The user has an option to :
   
- Add amount to the account
- Withdraw amount from the account
- View the current account balance
- Exit the application
  
4. The account balance will be updated as and when the deposit or withdrawal is made.
